A compact chess engine in 4,096 bytes of Python: a 0x88 board, negamax alpha-beta search with quiescence, a transposition table, null-move pruning, killer/history move ordering and piece-square evaluation. It plays the house gauntlet through the make.fun env, searching to a fixed node budget per move so every trial replays move for move.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
